# 🚀 Quick Start Guide

## Get Running in 3 Steps

### 1️⃣ Install
```bash
npm install
```

### 2️⃣ Run
```bash
npm run dev
```
Opens automatically at `http://localhost:3000`

### 3️⃣ Build
```bash
npm run build
```

---

## 📝 First Customizations

### Update Your Info (5 minutes)
1. Open [index.html](index.html)
2. Find & replace "Crekaar" with your business name
3. Update contact section (phone, email, address)
4. Update social media links

### Change Colors (2 minutes)
1. Open [style.css](style.css)
2. Edit lines 7-16 (CSS variables)
3. Change gradients on lines 18-20

### Add Your Projects
1. Replace placeholder images in portfolio section
2. Update project titles and descriptions
3. Change category filters (residential/complex/commercial)

## 🌐 Deploy

### Vercel (Easiest)
```bash
npm i -g vercel
vercel
```

### Netlify
Drag `dist/` folder after running `npm run build`

### Any Host
1. Run `npm run build`
2. Upload `dist/` folder contents

## ⚡ Pro Tips

1. **Images**: Use WebP format for 30% smaller files
2. **Testing**: Test on mobile devices, not just browser resize
3. **Performance**: Run Lighthouse audit in Chrome DevTools
4. **Forms**: Connect to FormSpree or your backend API
5. **Analytics**: Add Google Analytics before launch
